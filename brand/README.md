# Brand files

Drop the official Wacky's wordmark here as `wackys-logo.svg` (preferred), `wackys-logo.png` or `wackys-logo.webp`.
The header and footer pick it up automatically on the next build. Until then the approved "Est. 2007" seal is shown.

Source per the design system: `wackys_logo.png` (header), `logo 2016 no tag.png`, `og-image.png` on wackys.com.
Never retype the wordmark in a font.
